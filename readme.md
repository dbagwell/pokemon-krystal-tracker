# Pokemon Krystal Tracker

A [PopTracker](https://poptracker.github.io/) pack for use with the [Pokemon Crystal Randomizer](https://dbagwell.github.io/pokemon-crystal-randomizer/) and the [Pokemon Krystal APWorld](https://github.com/dbagwell/pokemon-krystal-apworld).

## Installation

1. Download the `pokemon_krystal_tracker_X.X.X.zip` from the [latest release](https://github.com/dbagwell/pokemon-krystal-tracker/releases/latest).
1. Place the zip file in the `packs` folder of your poptracker installation.

## Usage

1. Launch PopTracker and open the Map Tracker variant of the Pokemon Krystal pack.
1. Open the settings by clicking on the "Open Pack Settings" icon in the top left and select a logic preset by clicking on the Manual Logic Settings option until it shows the name of the preset you would like to use.

### Using with Archipelago

1. Click on the "AP" icon in the top left.
1. Enter the server host and port number.
1. Enter your slot name and the server password.
1. The logic settings will automatically be pulled from the server (the manual setting won't be used) and locations/items will automatically be tracked as they are collected.

Additionally you can open the pack settings and update the "Auto Tab" and "Smart Marts" settings to your desired preferences.

- ***Auto Tab***: While connected to the server, automatically updates the UI to show the map that is the most relevant to the players current in game location.
- ***Smart Marts***: Automatically marks marts as fully cleared if they've been viewed by the player and don't they don't contain any important items (progression items for the player or any items for other players) that the player hasn't already purchased.
